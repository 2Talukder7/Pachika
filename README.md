\# Pachika (পাচিকা) 🍲



A Bangladeshi cooking assistant that helps you discover recipes using ingredients you have at home. Chat in Bangla or English, scale recipes, use cooking timers, and get weather-based dish recommendations.





\## Features



\- 💬 Bangla and English chat

\- 🍛 Online recipe search with a local fallback

\- ⚖️ Adjustable serving sizes and ingredient quantities

\- ⏱️ Cooking timers and ingredient substitutions

\- 🌦️ Weather-based dish recommendations

\- 🗣️ Browser speech input and text-to-speech where supported

\- 🎨 Light and dark themes



\## Built With



\- Python and Flask

\- HTML, CSS, and JavaScript

\- \[TheMealDB](https://www.themealdb.com/)

\- \[Open-Meteo](https://open-meteo.com/)

\- Optional Google Gemini API integration



\## Known Limitations



\- The local recipe collection is limited.

\- Online results may not include every Bangladeshi dish.

\- Gemini recipe generation requires an API key and has not been fully verified.
